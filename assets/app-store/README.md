# App Store screenshots

The English screenshots in `en/iPhone-16-Pro/` are native 1206 × 2622 JPEG captures with fictional travel data. Build provenance is in `en/capture.json`.

In App Store Connect, open PastPins → the iOS version → App Previews and Screenshots. Upload the JPEGs under **iPhone with Dynamic Island (medium display)** for the English (Canada) localization. Recommended order: `01-world.jpg`, `03-list.jpg`, `02-places.jpg`. Save after uploading.

The website uses these same originals. To refresh them, follow [Capture release screenshots](../../development.md#capture-release-screenshots), review the artifact images, and replace this set.
